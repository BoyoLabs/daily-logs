# 2026-08-24

## Scoping the AI-native Linux distro

Started scoping a new multi-session project: a custom installable Arch-based Linux distro built AI-CLI-first, with Ollama, Claude Code, and Gemini CLI preinstalled and no desktop environment by default. Design work so far covers a keyboard-navigable tmux-based tabs system for the home screen, a themed login screen, a TUI settings app and file manager, and out-of-box driver/wifi support that doesn't depend on the AI tools already working. An MVP build plan is agreed but intentionally not started yet — the plan is to work through it in steps across sessions rather than all at once — and the project log was mirrored to the file server so it's browsable outside the project folder.
