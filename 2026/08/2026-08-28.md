# 2026-08-28

## From walkaround to a real game

The castle walkaround demo picked up actual game mechanics: goblins now spawn
at random points around the castle instead of a single fixed location, a
three-minute clock starts the moment you step in, each kill scores a point
shown live in a HUD, and running out of time shows a final score with a
replay button. Verified the whole hit-score-respawn-and-replay cycle with a
headless-browser test rather than eyeballing it in a real browser.
