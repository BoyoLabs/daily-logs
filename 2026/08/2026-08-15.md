## Fixed STL uploads greying out on mobile

Fixed the print server's upload form greying out STL files in mobile file pickers. Root cause: .stl has no registered MIME type on Android or iOS, so the accept filter alone left MIME-aware pickers unable to resolve what the file "is." Widened the accepted types to include the model/application variants plus the generic fallback most downloaders tag unrecognized extensions with — server-side validation was already extension-based, so this only changes what the OS shows as selectable.
