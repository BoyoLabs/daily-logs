# 2026-11-04

## File server archive empties itself

The file server's archive folder now expires its own contents: each archived item is stamped with the date it went in, and a daily sweep deletes it 90 days later. The date lives in the name rather than the file timestamp, because moving a file keeps its old timestamp, so an August design archived today would have looked three months old and been deleted at once. Tested on scratch data first, then most of the prints folder (207M down to 11M) was moved into the archive, leaving only in-progress work.

## Battery TTL Android app

Built a small sideloadable Android app that shows an estimated time until the battery is empty in the pull-down shade, no root needed: a Quick Settings tile that recomputes on every pull-down, plus an optional silent notification whose status-bar icon is the time itself. Putting it beside the system battery icon was ruled out, since that area belongs to the system UI and needs root or a custom ROM. The estimate blends a rolling drain average, which counts deep-sleep time, with smoothed live current, which reacts fast but only sees the phone while awake. It was built with the bare SDK tools instead of Gradle, smoke-tested on an emulator, and published to the file server's apps folder.

An advisory on the brotli library ("Broccoli2Shell") was checked against the server: the system library already had the distribution's backported fix, and the bundled runtime in the secrets server was on a patched release. ## TPU multitool sheath

The leather multitool belt sheath was made printable as its actual two layers in TPU, standing in for the leather: same traced outline and belt slots, with the rivet holes removed because the layers get plastic-welded round the edge, and the Boyo Labs chip logo debossed into the front layer. A first pass overbuilt it into a walled box with heat-stake pins and was corrected back to the simple version, since TPU flexes like leather and needs no molded pocket. Not printed yet.

## Two-color shop sign

The archived shop-sign burn stencil became a finished hangable printed sign: the light stencil plate glued onto a dark solid backing so the backing shows through the letters and portrait. Choosing the hang hole was a balance problem. With one twine loop over one nail, the 12 o'clock spot in the gear-tooth band keeps the center of mass almost straight under the nail at any cord length, while the 9 o'clock spot sits at the center of mass's own height and would flop. Between the teeth, keeping 3 mm of plate all round caps the hole at about 3.6 mm. Thickening the backing to 0.75" later shifted the center of mass toward the solid end, so the far-end hole moved 30 mm inward to keep it level. A test print of one tile pair comes before the design is called final.

## Tunnel outage traced to wifi

All public services were unreachable for roughly 50 minutes in the afternoon. The cause was the server's wifi link, not the tunnel client: the nearby mesh node it normally uses dropped the connection, and the box fell back to the main router's far weaker radios, where it could not reach the edge. It re-associated with the mesh node and every tunnel re-registered within minutes with no manual action. The tunnel watchdog correctly did nothing, since it only restarts dead processes and the processes were alive throughout. Why the mesh node dropped is unconfirmed, and the box has no wired fallback, so wifi is a single point of failure for every public service.

## Travel-size board replacement pieces, from phone photos

Designed three replacement pieces (5-arm star, parallelogram, rhombus) for a travel-size Perfection board, measured entirely from phone photos since no dimensions or models exist online. A homography off the board's grid ribs gave a true top-down image, a PCB ruler in frame set the scale, and the symmetric existing pieces coming out isotropic to about 1% validated it. One finding: the "square-ish" hole is really a 20.8 x 18.9 mm parallelogram, which is chiral and cannot be mirrored. Not yet printed or test-fit.
