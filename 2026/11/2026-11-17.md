# 2026-11-17

## Lanternfall, rebuilt as a ranked wave-survival game

Lanternfall stopped being a co-op mission and 3v3 PvP game and became a solo, first-person, zombies-style score chaser: escalating spectre waves on the old town-square arena, four power-ups, one life. Its multiplayer is now a monthly ranked season instead. Ranking is relative rather than threshold-based: each rank holds a fixed share of the ladder, you climb by topping your rank and passing the lowest player above, ranks are kept once earned, and the top tier shows a numbered placement. Marked bots populate the ladder while it's small and are tuned slightly softer than real players. It ships both as a browser build, on Godot's lighter renderer with 1K textures (about 59 MB instead of 130), and as Linux and Windows downloads, all sharing one account and rank database.

## Scoring a game whose scores can't be trusted

A browser game's score submission is just a request anyone can forge, so the server never takes a score at face value. It re-derives every score from its parts (kills by type, waves held, double-points bonus) and bounds each part by what the wave schedule can physically produce in the time measured server-side. The ladder bots are a pure function of season, index and time, so they need no stored state at all.

## The first playtest, and calibrating with an autopilot

The first real runs all died in wave 1 within a minute, and the phone controls didn't respond. The phone bug was reproduced before fixing it, by driving the browser build in an emulated-phone headless Chrome with real touch events: every touch also arrives as a left mouse click, so pushing the move stick just fired the lantern. Difficulty was recalibrated against a deliberately imperfect autopilot that died about as fast as the real runs did. Early waves became a ramp, and a new mechanic where every hit staggers a spectre back stopped the wall-pinned deaths, taking the autopilot's typical run from 18 seconds to about 4.4 minutes against a five-minute target. Controls became remappable, and new accounts now get the intro and an interactive tutorial worded for whatever device they're holding.

## Friends, co-op and rank emblems

Players can now add friends, see who's online, and play ranked co-op in parties of up to four. Peer-to-peer was off the table (browsers can't accept connections), so the game server relays packets between a host and its guests, under a small custom multiplayer peer so the match code uses ordinary remote calls. Scores stay individual: each kill goes to whoever's light finished it, and the server's caps scale with party size using the same integer formula as the game. A set of 22 generated vector emblems escalates through the ranks, with each tier changing the medallion and icon and each step adding frame detail. A test had two real copies of the game befriend each other, party up and play through a throwaway server, with both runs accepted on their own points.

## Phone polish

A run of small releases made the browser build work properly on phones. Dragging the cast button now aims too, menus get finger-sized buttons and a compact layout, and the full-screen toggle became easy to find. Installed Android apps go full screen on the first tap, and iPhones get Add to Home Screen instructions, since Safari has no full-screen mode for web pages. Phone browsers only raise the keyboard for a real HTML text field focused during the tap itself, which game-drawn text boxes never are, so typing on a phone now opens a small native input dialog.
