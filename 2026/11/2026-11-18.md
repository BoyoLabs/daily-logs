# 2026-11-18

## Lanternfall: an all-time rank built for a small player base

Ranking players against each other breaks down when there are only a few of them, so the new all-time rank is built only from a player's own season finishes, on the same Ash-to-Dawnbringer scale and emblems. After a day of tightening it settled as a rolling average of your last four seasons with skipped seasons counted as the bottom, so old seasons roll off and anyone who comes back can fully recover within four months. A lifetime leaderboard was considered and dropped because it would lock newcomers out forever. Alongside it, each new season now starts you at half the rank you finished on (only if you played), returning players start from their last played rank halved once per month away, and tappable player cards show a season-by-season history.

## Lanternfall on phones

A phone playtest drove a round of fixes. Menus wouldn't scroll by touch because their rows are buttons that swallow the drag, so drag-scrolling is now handled by hand. Typing failed because full-screening only the game canvas hid the native typing dialog, so the game now full-screens the whole page. The suspected cause of players seeming to jump around in fights was frame-time spikes from a dynamic light on every bolt, impact and kill, which the browser renderer redraws per light. The browser build now keeps the glow but drops those lights, and it interpolates physics so frame dips look smooth instead of like teleports.

## Lanternfall co-op: smaller parties, shared points

Co-op parties are now capped at three, which is easier to fill with a small player base. Because co-op splits the kills, a co-op seat earned less than a solo run (about 80% in a duo), so each player now also gets 40% of a duo partner's points or 30% of each trio teammate's. That works out to roughly 1.1 to 1.15 times a solo run. The share is credited server-side only from teammates' accepted runs, so it can't be self-claimed.

## Lanternfall: in-game updates for the downloads

The downloaded builds now update themselves. A tiny boot loader mounts an installed patch over the embedded game before anything else loads. Each release builds patches of only the changed files from each of the last eight versions, and the first real one was about 50 KB against a 120 MB full download. Copies too old for a patch can still update in place with the full current data pack. Only an engine upgrade forces a real re-download.

## Lanternfall: a brighter, faster browser build

The browser build was much darker than the download, having lost the fog scatter, glow and per-bolt lights. It now has warmer ambient light, a modest exposure lift and a dim warm haze in the distance, so dark spectres read as silhouettes. A browser performance profile renders the 3D scene at a resolution matched to the screen's pixel density and halves the physics rate (interpolated). It also drops real-time shadows and halves the particles. In software-rendered phone emulation that took the build from about 19 to about 32 frames per second, with gameplay unchanged. The browser menus also gained a link to the PC and Steam Deck downloads, which share the same account and ranks.

## File server: leather pattern stencils kept

The archived set of leather-pattern stencils (14 pattern projects plus older reference PDFs) was moved out of the file server's 90-day auto-expiring archive into its own folder under prints, so it no longer expires.

## A backing-track engine

A new engine renders a short song spec into a fully arranged backing track for original instrumental songs, with the lead guitar standing in for the singer. Output is stems, a chord chart with soloing targets, MIDI and a verification report. The best free acoustic sounds turned out to be CC0 sample libraries that a standard SoundFont synth can't play, so the engine maps their samples from filenames and plays them through its own small sampler. Hitting a streaming-style loudness target took per-instrument compression plus one limiter gain curve shared by the mix and every stem, so the stems still sum exactly to the mix.

## Five rounds to the first finished track

The first song, a slow 12/8 G-minor ballad called Cinder Road, took five listen-and-fix rounds. Background static was traced to the cymbal samples' own recorded room sound stacked under the engine's reverb. A slight drift off the beat turned out to be a realistic "band breathes" tempo wander, which is wrong for a track someone plays against, so it's now off by default. Perfect timing then needed more than on-grid notes, because the samples themselves start late, so the engine now lines up each sample's perceived attack with the beat (from 8-10 ms late to about 0). A "plane flying" sound was settled by short A/B clips as the continuous brush swirl, which was dropped. v5 is the finished version, and its perfectly quantized, attack-aligned settings are now the template for every new song.

## A second song, and a country band

A second song, Coyote Wages, is an A-minor country two-step at 116 bpm. It added a country palette: a brushed train beat, walking upright bass, boom-chick rhythm guitar, mandolin chop, banjo rolls, and a fiddle playing written lines and fills. The only clearly licensed sampled banjo was recorded about 42 cents sharp, so every sample's pitch is now measured and the engine retunes from the measurement. The synth voices measured 18-23 ms late, so each note's attack latency is probed and scheduled early, which brings every part within about 1 ms of the grid.
