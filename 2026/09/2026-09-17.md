# 2026-09-17 – 2026-09-18

## Deck + server as one system

Talked through how the Steam Deck and the home server fit together: the Deck is a thin client bringing portability and ergonomic input, the server supplies compute, storage, and Claude Code — together they cover everything wanted, neither alone. Mid-conversation, realized the Deck is a full PC rather than a console, and can run background apps like an SSH session while still in Gaming Mode. Typing on the touchpad keyboard is the one real friction point, "pretty okay" given the constraint, but still preferred over a Chromebook with a better keyboard on pure ergonomics.

## 3D print output convention

Set a standing convention: any 3D design work done through Claude Code lands its `.stl` output directly in the file server's prints folder, so new prints preview from the Deck with no extra steps.

## Why the Deck works as a PC replacement

In a later thread, reached from the Deck's browser-based terminal, named the trackpads specifically as the reason no other handheld PC works as a real computer replacement — they're what makes it usable as an actual PC rather than just a game console.

## Landing on "no single device"

Extended that into a broader conclusion after a long-running search for "one device to rule them all": decided against that goal entirely. A mobile client (checking a game on a phone, say) is fine for simple cases, but mobile OS multitasking is bad enough that converging everything onto one device isn't worth it — the better answer is the right specialized device per context, Deck for full PC work and phone only for simple tasks.

## Terminal without leaving Gaming Mode

Followed through the same day: added a terminal app to the Deck as a non-Steam game, closing the loop on the "Deck is a full PC" thread — no more switching to Desktop Mode just to get a terminal. Also spent real time on custom artwork for the non-Steam game shortcuts so the Gaming Mode library looks native instead of showing placeholder icons, part of the same push to minimize how often Desktop Mode is needed at all.

## Steam button remap: upstream bug, no workaround

The next day, tried remapping a keyboard shortcut onto the Steam Deck's physical Steam button and hit a known upstream bug blocking it. Looked at more invasive fixes, decided against them, and settled on just pressing the physical button until an upstream fix ships.

## VOO intraday move alert

Also built an email alert that watches VOO through the trading day: a scheduled script pulls a quote via a market-data library and emails when price crosses a threshold band, in either direction, including a re-notify if it retreats back through a lower band. Tuned the threshold live over the morning — started at ±0.2%, bumped to 0.3% since that was too close to normal noise, then settled on 0.25% so the ladder lands on clean 1% multiples. Runs during the extended trading day, deliberately not overnight, so a move while asleep doesn't trigger a notification — the first daytime check still catches the full move. True round-the-clock coverage would need authenticated access to the broker's own overnight session feed, left as a possible future build rather than tackled now.
