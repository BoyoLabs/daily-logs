# 2026-09-13

## Scoped a single-purpose OSRS streaming host

Looked into whether one machine could stream just a single game — not a
full remote desktop — to any device, with input, so a persistent OSRS
session could be picked up from anywhere. Verdict: it's a good fit, since
the game is light enough that video encode and network are the only real
costs, and "only the game" is achievable by giving it its own display
running one program rather than trying to sandbox a full desktop down to
one app. Two ready-made streaming tools were ruled out for reasons
specific to this box (no working container runtime, no init system) and a
promising built-in feature turned out to be Windows-only for now, leaving
a lower-level streaming stack as the practical path — with networking,
not video, as the harder problem, since the protocol wants a spread of
ports the existing tunnel setup can't carry.

## Follow-up moved the real target to a locked-down browser tab

A later turn in the same conversation changed the requirement in a way
that ruled out the whole first answer: the actual client is a
locked-down work machine with no installs, where an existing
browser-based remote tool had always been unreliable. Tracing *why*
pointed to a network-layer mismatch rather than a bad tool — that class
of tool depends on a media path corporate networks routinely block, so it
falls back to a slow relay, and any similar tool would hit the same wall.
The fix is a different class of streamer, one that carries everything
over a single ordinary web connection so it looks like normal browser
traffic; one candidate already does this well but is still a pre-release
build, which matters when the whole point is something trustworthy
enough to rely on. The piece that doesn't depend on that choice is the
dedicated single-purpose display itself — built once, with whichever
streamer sits on top of it swappable later. Nothing built yet; this stays
a research thread, with the added wrinkle that streaming onto an
employer-managed machine is a judgment call for him to make, not a
technical one.
