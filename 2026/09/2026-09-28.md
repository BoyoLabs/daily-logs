# 2026-09-28

## Craft-brand site down after the overnight reboot

The craft-brand site didn't come back after the overnight reboot. Its tunnel's log file had picked up the wrong ownership during an earlier setup session, so the tunnel couldn't write its log and never launched, either at boot or from the auto-restart watchdog. Correcting the ownership let the watchdog bring it back. Lesson: anything created during a setup session with elevated permissions needs its ownership checked before the first reboot.

## Ironman: an offline OSRS-style RPG, from design calls to a v0.1 proof of concept

Kicked off the build from a saved prompt and settled the open design calls first. Art and sound come from Kenney's CC0 asset packs, and the starter zone is a classic medieval riverside. Past the hand-authored content, both monsters and gear extend forever through formula-generated tiers, so gear-loss death stays meaningful at every depth. v0.1 shipped as a downloadable zip: one riverside village, Fishing, Cooking, melee combat, a bank, continuous auto-save with no save UI, and full controller navigation for the Steam Deck. The code uses plain classic scripts instead of ES modules, because browsers block modules over `file://` and the game has to run by double-clicking `index.html`. An end-to-end browser test caught two real bugs. A grid named `path` was overwriting the pathfinding function, and auto-retaliate walked a just-respawned player straight back into the fight that killed them.

## Playable straight from the file server, without loosening it

The file server only serves an allowlist of file types inline, a deliberate guard against stored XSS, and script, style and font files aren't on it. Rather than relax that, a small build step now inlines all the game's code, styles and font into a single HTML page, with sprites and sounds served as ordinary files. No server change was needed. Publishing is also automatic now: any edit to the game rebuilds both the browser-playable copy and the download.

## Steam Deck playtest fixes (v0.1.1–v0.1.2)

The first Deck playtest brought fullscreen, much more visible animation (attack lunges, hit flashes, a fishing line and bobber, level-up bursts), chunkier health bars and a target frame. Gamepad handling was also fixed: the game only read the first controller the browser reported, and the Deck can report several. Then came a hotfix for a full freeze when walking away from a fishing spot. A cosmetic animation flag outlived its action by a tick and crashed the renderer. Because the main loop only scheduled the next frame after drawing succeeded, that one error stopped everything. The bug is fixed, and the loop is restructured so a rendering error can no longer take down input or game logic.

## A title, a naming rule, and the combat triangle (v0.2–v0.3.1)

The game became "Ironman: Riverside". The rule is that it's always titled after its newest location, generated from data rather than hand-edited. The title screen has a hand-pixeled knight in absurdly heavy plate and a player-facing update log. The build refuses to publish a version bump that has no log entry. v0.3.0 added Ranged and Magic plus a melee/ranged/magic triangle. Every monster wears an armour type that one style beats and another is resisted by. Each style gets a one-handed weapon that allows a shield and a harder-hitting two-hander that doesn't. Armour is now drawn on the character, and the release also added shops with starter-tier stock only, colour-coded monster levels, drag-to-rearrange inventory, save-file transfer (a deliberate exception to the no-save-UI rule), and item stat cards that work by hover or by controller focus.

## Attack and Strength merged into one Melee skill (v0.4.0)

Attack and Strength became one Melee skill, which makes Melee, Ranged and Magic symmetric. Every combat style now offers the same three training options. The migration was designed so existing characters can't lose anything. The first pass let a mid-level character's combat level drop by two; testing caught it, and a floor now ensures combat level can only stay the same or rise. Two older tests also turned out to be silently checking a fresh character instead of the old save they were meant to load, and both were fixed.
