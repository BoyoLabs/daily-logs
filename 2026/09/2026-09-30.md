# 2026-09-30

## Steam Deck turned into a full handheld PC

Gaming Mode on the Steam Deck was converted into a desktop-PC-equivalent experience by patching Steam's own interface directly, working with Claude — no Decky Loader or plugin framework involved. The hard part was a wallpaper-switcher app that changes backgrounds live from inside Gaming Mode; alongside it, a Kindle app, Discord, Chrome, Plex and a terminal running Claude Code all now run natively there. A few minor bugs showed up, none frequent or severe enough to matter, and the net effect is a Deck that works as a full PC that happens to be handheld.
