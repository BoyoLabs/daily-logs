# 2026-10-11

## Print queue showed the printer offline while it was powered on

The print queue page reported the printer as offline even though it was on. The printer's USB-serial link had dropped and re-enumerated the previous morning after a power-cycle or replug, which killed the print controller's serial connection; the controller does not reconnect on its own, so it had been sitting closed for over a day. A single reconnect command through the controller's API brought it straight back to operational with no code change. Reconnecting automatically when the port reappears is a possible follow-up, not built.
