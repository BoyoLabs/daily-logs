# 2026-10-02

## A decision model for the tunnel watchdog: researched, ruled out

TypeSafe's "Jev" decision model was looked at as a possible replacement for the watchdog that restarts dead tunnels. Verdict: not a replacement. Jev is cloud-API-only, with no downloadable weights and an early-access waitlist, and the watchdog's actual job — is the process alive — is deterministic, so a probabilistic model would add latency and a new failure mode for no gain. Open self-hosted clones exist, and a small CPU-capable encoder model would be feasible on the server, though noticeably less accurate than the real thing; one "OpenJev" turned out to be a crypto-token resale site and is treated as untrustworthy.

The one place a decision model could plausibly fit is classifying *why* a tunnel stayed down after a restart — transient, auth, config, upstream, or no network — to choose between retrying and alerting. Even that is probably better served by a rules table first, with a classifier only as a fallback for log lines the rules don't recognize. An advisory-only, shadow-mode trial of a self-hosted classifier is parked for now.

## Ironman v0.7.1: save transfer that fails out loud

Save download and upload in Ironman, the offline OSRS-style RPG, were reported as "nothing happened." It couldn't be reproduced in the test browser — the logic was fine — but every real-device failure mode was silent: a scripted click on a detached file input, no user gesture from a controller press, errors written to a log hidden behind the menu, and a `.json` type filter. Both were reworked into their own windows with visible status, a real in-page file button, a tap-to-redownload link, drag-and-drop, and a no-file copy/paste route for the save text. The test suite was extended to cover every route and all 12 suites pass. Which device and browser originally failed is still unknown, so the fix is unconfirmed there.

## Ironman v0.7.2: playable by anyone from one link

The game became playable from a single public link, in the browser. The decision was to use the file server's existing share-link feature rather than the demo hub or a public repo. Share links cover a single file, so instead of adding folder sharing — a bigger public surface — the build now also emits one self-contained page with every sprite and sound embedded and resolved through a small asset resolver. No file-server code changed and the gated test build stays gated. Verified from a logged-out browser: zero extra network requests, and saves stay in each player's own browser.
