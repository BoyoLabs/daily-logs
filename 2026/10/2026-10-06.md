# 2026-10-06

## Income tracker: per-position monthly estimate

The Positions table gained an "Est. Monthly" column beside the existing annual forward-income figure. It is derived as the annual figure divided by twelve (shares times the most recent per-share payout) rather than computed separately, so the per-row numbers sum exactly to the headline monthly income stat. It is also exposed on the JSON endpoint the terminal portfolio client reads, though that client doesn't render it yet.

## Paper tab retired, Position Analysis tab added

The practice-trading tab came off the web surface and a Position Analysis tab took its place; the underlying data and background snapshots were deliberately left intact, so paper trading is frozen rather than deleted. The new tab shows, per held fund, per-share price change next to that month's distribution and the net of the two, as monthly bars or cumulative lines over a selectable range (default: since first purchase). The point is to see whether a high-yield fund's payout is real income or price erosion coming back. Two decisions worth keeping: figures are per share so regular contributions can't contaminate the comparison, and price history is pulled unadjusted, because dividend-adjusted prices would count every payout twice. Chart colors went through a palette validator, and headless screenshots at desktop and phone width caught one clipped axis label.

## Slow WiFi report: the server's own ceiling is not the line's

The server box measured roughly 70-85 Mbps down and 64 up on a 1 Gbps plan, but it sits on WiFi with a single-stream uplink, so that is its own ceiling rather than the line speed. A five-minute latency run showed near-zero loss and a few brief 100-300 ms spikes that also appeared on the router hop, which points at the WiFi side. The box itself was nearly idle, so it isn't what slows other devices. The throughput-over-time run failed (the speed server rejected the large request), so a wired or other-device test is still the open question.

## Printer offline: a physical fault, not a software one

The print site showed the printer offline because its USB serial adapter dropped off the host mid-morning and the port came up empty. The print app, the print host software and the webcam were all healthy and the queue was empty, so this needs a physical check of the cable and power rather than any software change.

## Push-to-talk voice input on the handheld

Local push-to-talk speech-to-text was built for the handheld, running entirely on-device with the text injected into the terminal, to speed up input; the keyboard stays as the quiet-mode path. It is built and working well. Model size, latency and the binding weren't captured at the time.
