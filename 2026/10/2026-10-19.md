# 2026-10-19

## The print queue's time remaining, fixed

The print queue showed about 23 hours left on a print that really needed about 6. The printer software guesses time remaining from how far through the file it is, but gcode bytes aren't spread evenly over print time. The print server now reads the slicer's own per-layer time markers and scales them by how fast the print is actually going, which brought the estimate down to about 3 hours on the live print. That matched the real pace. The progress bar now uses the same timeline, so it read about 45% instead of 10% and agrees with the timer. The internal "is this print finished" check still deliberately uses the printer software's raw number, so a display change can't get a job cleaned up or requeued early.

## Checking the new estimate near the end of a print

Late in a 5.7-hour wallet-stencil print, the new estimate said about 1h50m left while the printer software said about 33 minutes. The new estimate was right. The solid bottom and top layers take about 40 minutes each but make up only a small part of the file, so any guess based on file position falls apart near the end. The real elapsed time stayed within about 9% of the slicer's per-layer prediction for the whole print. The check also showed that the slicer's own header total for the file (1.85 hours) is wrong, so the per-layer markers are the number to trust.

## A pauldron pattern as a capability test

As a test, a simple riveted leather pauldron pattern was drafted from a reference photo of a Norse-style one. It has a shoulder cap, a yoke plate, three arm lames, buckle tabs, and straps, with no stitching or darts, since the cap gets its shape from wet-molding. The cap and lames are drawn as rings of one flattened cone, so the overlaps stay an even width and the lower lames flare out over the arm. A script generated it as a tiled, actual-size letter PDF plus a full-size SVG. The pauldron won't be made, but the approach works: describe a leather piece and get a pattern ready to print and cut, without needing to be a skilled pattern drafter.

## First real use: an ID badge holder

That approach got its first real use right away: a riveted leather ID badge holder for a standard wallet-size card, made as two 3D-printable cutting stencils. The back piece has a top tab for a key ring, and the front has a display window and an open top for the card. Nine double-cap rivets replace the stitching in the reference photo, and the rivet posts themselves hold the card in place.
